Built for privacy

Every feature designed with anonymity as the foundation, not an afterthought.

🔐

End-to-end encrypted

X25519 ECDHE key exchange + AES-256-GCM authenticated encryption. Every message is encrypted before it leaves your machine.

🧅

Tor support

Route connections through Tor SOCKS5, or expose your hub as a Tor hidden service. Your IP stays yours.

👥

Multi-user hubs

Star topology with broadcast. The hub operator is admin and can promote others, kick, mute, and configure at runtime.

📺

Terminal-native TUI

Built with ratatui + crossterm. No browser, no Electron, no telemetry. Just a fast, keyboard-driven interface.

📄

File transfer

Chunked v2 protocol with 64 KiB blocks, path-traversal protection, and configurable max size. Encrypted end-to-end.

🎨

Markdown & emoji

*bold*, _italic_, `code`, and 30+ emoji shortcodes like :onion: 🧅

⚙️

config.json driven

Everything configurable: history, roles, anonymity, permissions. Change settings at runtime with /config set.

🌍

UTF-8 / Turkish

Full multi-byte character support. ş, ğ, ü, ö, ç, ı, İ — all work in messages, nicks, commands, and file paths.

🛡️

Zero unsafe code

The entire codebase is unsafe-free. Rust's ownership model guarantees memory safety without compromise.

Quick start

Up and running in 60 seconds.

📋 Prerequisites

# Rust 1.96+ (stable)
curl --proto '=https' --tlsv1.2 -sSf https://sh.rustup.rs | sh -s -- -y

# (Optional) Tor for anonymity features
sudo apt install tor  # Debian/Ubuntu
Step 1 — Clone & build
git clone https://github.com/yourname/onionchat.git
cd onionchat
cargo build --release
# Binary: target/release/onionchat
Step 2 — Start a hub (Terminal 1)
# Listen on port 8080, accept multiple peers
./target/release/onionchat --listen 8080 --multi
Step 3 — Connect as a peer (Terminal 2)
./target/release/onionchat --connect 127.0.0.1:8080
Step 4 — Chat!
# Type a message and press Enter

Anonymity is the foundation

Most chat apps trust a central server with your metadata. OnionChat is built differently — your IP is never displayed, history is off by default, and Tor is a first-class citizen.

  • Peer addresses are hidden — shown as peer-<id>
  • History is OFF by default (anonymity-first)
  • No accounts, no phone numbers, no email
  • No telemetry, no analytics, no phone-home
  • Tor SOCKS5 for client connections (--anon)
  • Tor hidden service for hubs (--hidden-service)
  • strip_metadata: true by default in config
