# Bug Fixes — 2026-06-28 v3 (Chat TUI)

Bu oturum, OnionChat'ın birincil özelliği olan **sohbet TUI'sini**
ekledi. `--connect` (dosyasız) ve `--listen` artık etkileşimli ratatui
tabanlı TUI'a giriyor; kullanıcılar mesaj yazıp gönderebilir, peer'dan
gelen mesajları görebilir.

## Önemli Değişiklikler

### 1. Yeni modül: `src/chat.rs`
- **Sorun**: `--connect` (dosyasız) "chat mode placeholder" yazıp çıkıyordu;
  gerçek bir sohbet yoktu.
- **Çözüm**: RFC 1928 benzeri basit mesaj protokolü. Her mesaj
  `[0x01][utf-8]` formatında. Dosya transferi `0x02` ile başladığı için
  tip byte'ı çakışmaz. Detaylar için [[chat-tui]].
- **Dosya**: `src/chat.rs` (yeni, ~130 satır + 8 test)

### 2. `file_transfer::recv_file_after_version` (refactor)
- **Sorun**: Listen tarafı peek edip chat mi dosya mı olduğuna karar verince,
  dosya transferinin sürüm baytını zaten tüketmiş oluyordu. `recv_file`
  tekrar sürüm baytı okumaya çalışırdı.
- **Çözüm**: `recv_file` ikiye bölündü:
  - `recv_file` — sürüm baytını okur + doğrular, sonra `recv_file_after_version` çağırır
  - `recv_file_after_version` — sürüm baytı zaten tüketilmiş kabul eder
- **Geriye dönük uyumluluk**: `recv_file` imzası değişmedi, mevcut testler geçiyor.
- **Dosya**: `src/file_transfer.rs`

### 3. `ui.rs` tamamen yeniden yazıldı (chat TUI)
- **Sorun**: Eski `ui.rs` sadece tek bir çerçeve çizip çıkıyordu;
  etkileşimli event loop yoktu.
- **Çözüm**: Tam ratatui + crossterm tabanlı chat TUI:
  - Title bar, sohbet geçmişi, mesaj kutusu, status bar layout
  - `tokio::select!` ile ağ ve klavye olaylarını birleştirir
  - `spawn_blocking` ile crossterm blocking poll'u ayrı thread'de
  - UTF-8 çok baytlı karakter desteği (Türkçe `ş`, `ğ`, `ü`)
  - Scroll, cursor movement, backspace, home/end
  - Peer disconnect algılama + sistem mesajı
- **Dosya**: `src/ui.rs` (~520 satır + 21 test)

### 4. `main.rs` chat TUI'na bağlandı
- **Sorun**: `run_connect` (dosyasız) sadece `recv_message()` çağırıp çıkıyordu.
- **Çözüm**:
  - `run_connect` (dosyasız): `Connection::connect` + `ui::run_chat_tui`
  - `run_listen`: peek ilk mesaj, eğer `0x02` ise `recv_file_after_version`,
    değilse `chat::decode_chat` + `ui::run_chat_tui`
  - `CliUiMode` ve `From` impl kaldırıldı (artık kullanılmıyor)
  - `run_tui` (argümansız) yardım mesajı yazdırır
- **Dosya**: `src/main.rs`

### 5. Clippy `collapsible_if` uyarısı
- **Sorun**: `if let Ok(true) = poll { if let Ok(...) = read { if ... { } } }`
  üç katmanlı if — clippy bunu `let ... && let ... && ...` olarak
  collapse etmeyi önerdi.
- **Çözüm**: Rust 2024 let-chains syntax'ı kullanıldı.
- **Dosya**: `src/ui.rs`

### 6. Lifetime syntax uyarıları
- **Sorun**: `fn line_to_spans(line: &ChatLine) -> Spans` — `Spans<'a>`
  lifetime'ı gizli, clippy `mismatched_lifetime_syntaxes` uyarısı verdi.
- **Çözüm**: `Spans<'_>`, `Vec<Spans<'a>>` açık lifetime'lar.
- **Dosya**: `src/ui.rs`

### 7. `dead_code` uyarıları
- **Sorun**: `chat::send_chat` (kullanılmıyor, `send_chat_split` tercih edildi),
  `file_transfer::recv_file` (artık `recv_file_after_version` kullanılıyor),
  `ui::run` (legacy) — üç dead_code uyarısı.
- **Çözüm**: Üçüne de `#[allow(dead_code)]` eklendi, public API olarak korundu.
- **Dosyalar**: `src/chat.rs`, `src/file_transfer.rs`, `src/ui.rs`

## Yeni Özellikler

- **`chat::CHAT_MSG_TYPE = 0x01`** — sohbet mesaj tip öneki.
- **`chat::send_chat(conn, text)`** — `&mut Connection` ile mesaj gönder.
- **`chat::send_chat_split(sender, text)`** — `Sender` ile mesaj gönder (TUI için).
- **`chat::decode_chat(msg)`** — mesajı çözümle, `Some(text)` veya `None` (dosya).
- **`file_transfer::recv_file_after_version`** — sürüm baytı tüketilmiş hali.
- **`ui::ChatState`** — TUI state (messages, input, cursor, scroll, connected).
- **`ui::ChatLine`** — sohbet satırı (Sent/Received/System + text + timestamp).
- **`ui::run_chat_tui(conn, mode, peer, initial_msg)`** — ana chat TUI giriş.
- **`ui::draw_chat`** — ratatui ile layout çizimi.
- **`ui::handle_key`** — klavye olayı işleyici.

## E2E Doğrulama

Python PTY tabanlı test (`scripts/test_chat_e2e.py`) iki proses başlatır
ve çift yönlü mesajlaşmayı doğrular:

1. **Connect → Listen**: "merhaba" gönderildi ✓
   - Connect TUI'da "merhaba" yazılır, Enter'a basılır
   - Listen tarafı peek eder, chat mesajı olarak decode eder, TUI'a girer
   - "merhaba" listen ekranında görünür

2. **Listen → Connect**: "selam" gönderildi ✓ (çift yönlü!)
   - Listen TUI'da "selam" yazılır, Enter'a basılır
   - Connect tarafı mesajı alır, ekranında gösterir

3. **Uzun mesaj**: "uzun mesaj test" ✓
   - Çok kelimeli mesaj doğru iletilir

Tüm mesajlar E2EE (ECDHE + AES-GCM) ile şifrelenmiştir. SOCKS5
anonimlik katmanı korunmuştur (`--anon` veya `--socks5`).
