# v0.2 Feature Release

Bu sürüm OnionChat'ın birincil özellik setini tamamlar: çoklu-kullanıcı
sohbet, mesaj geçmişi persistansı, markdown rendering, slash komutları,
ve Tor hidden service desteği.

## Yeni Modüller

### 1. `history.rs` — Mesaj Geçmişi Persistansı

JSON Lines formatında `~/.onionchat/history.jsonl`'a mesaj kaydeder.
Append-only, hata tolerant (bozuk satırlar atlanır). TUI açılışında son
50 mesaj yüklenir. `/clear` komutu dosyayı temizler.

Detaylar için: `src/history.rs` (14 test).

### 2. `markdown.rs` — Inline Format Rendering

Sohbet mesajlarındaki inline formatlamayı ratatui `Span`'larına çevirir:
- `*bold*` → kalın
- `_italic_` → italik
- `` `code` `` → sarı, sabit genişlikli
- `:emoji:` → emoji shortcode (30+ emoji: `:smile:`, `:heart:`, `:onion:` vb.)

Detaylar için: `src/markdown.rs` (21 test).

### 3. `commands.rs` — Slash Komut Parser

`/komut argüman` formatını parse eder. Komut çalıştırma `ui.rs`'ın
sorumluluğunda; bu modül sadece parse eder.

Desteklenen komutlar:
- `/help` — yardım metni
- `/quit`, `/exit` — çık
- `/clear` — geçmiş temizle
- `/send <path>` — dosya gönder (tek-peer modunda placeholder)
- `/nick <name>` — takma ad (placeholder)
- `/who` — bağlı peer sayısı

Detaylar için: `src/commands.rs` (16 test).

### 4. `tor_control.rs` — Tor Hidden Service

Tor control port (`127.0.0.1:9051`) üzerinden `ADD_ONION` komutu
göndererek hidden service oluşturur. Cookie authentication kullanır.
Dönen `HiddenService` onion adresini içerir.

Gereksinimler: Tor sistem servisi, `ControlPort 9051`,
`CookieAuthentication 1`. Test ortamında Tor olmadığı için entegrasyon
testi elle yapılır.

Detaylar için: `src/tor_control.rs` (4 test).

### 5. Multi-peer Star Topoloji (`ui.rs` — `run_chat_tui_hub`)

Hub modunda birden fazla peer'ı paralel kabul eder. Her peer için ayrı
task, ortak `ChatState`. Gelen mesajlar tüm peer'lara broadcast edilir
(star topoloji). `--multi` veya `--hidden-service` flag ile etkinleşir.

```
        [Spoke 1] ─┐
                    ├── [Hub] ── broadcast
        [Spoke 2] ─┘
        [Spoke N] ─┘
```

## CLI Yeni Flag'ler

```bash
onionchat --listen 8080 --multi              # hub modu
onionchat --listen 8080 --hidden-service     # Tor hidden service + hub
onionchat --listen 8080 --hidden-service \
          --tor-control 127.0.0.1:9051 \
          --tor-cookie /var/run/tor/control.authcookie
```
